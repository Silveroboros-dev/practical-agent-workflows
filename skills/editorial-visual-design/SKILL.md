# Editorial Visual Design

Use this skill when an editorial-gallery direction suits the user's brief. Confirm the intended audience and medium from the task context. Honor an existing brand, accessibility requirement, or requested style over this reference palette.

## Read order

- Read `references/style-cheat-sheet.md` before giving visual direction.
- For redesigns, reusable systems, deeper critiques, decks, documents, or prompt packs, also consult the relevant sections of `references/style-resolutions.md`.
- For concrete web or UI work, token choices, or component treatments, use `references/visual-system.html` and `references/component-variants.html` as local visual specimens. Inspect their source or open the files when the host supports it. Resolve these paths relative to the installed skill directory supplied by the host.

## Output

Use the requested format. For a critique or design brief, a useful compact frame is:

- `Direction`: the intended first impression and main visual move.
- `Keep`: existing strengths or principles to preserve.
- `Avoid`: specific drift risks for this task.
- `Prompt language`: reusable wording when it helps implementation or image prompting.

Translate the style through composition, hierarchy, typography, and interaction before adding ornamental components. Use subject matter and negative anchors for image prompts, rather than mood words alone. Keep the style's details adaptable: charcoal, brass, paper, glass, and asymmetry are examples, not universal requirements.
